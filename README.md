# QR Code Generator

Python ve Tkinter kullanılarak geliştirilmiş masaüstü QR kod oluşturucu uygulaması.

## Özellikler

* URL'den QR kod oluşturma.
* QR kodunu SVG formatında kaydetme.
* Tkinter ile grafik kullanıcı arayüzü (GUI).

## Kullanılan Teknolojiler

* Python
* Tkinter
* PyQRCode

## Öğrendiklerim

Bu projede Tkinter ile masaüstü arayüz geliştirmeyi, kullanıcıdan veri almayı ve dosya kaydetme işlemlerini uyguladım.
